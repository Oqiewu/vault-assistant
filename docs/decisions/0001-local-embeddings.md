# 0001 — Локальная embedding-модель вместо OpenAI API

**Статус:** принято — 2026-09-13

## Контекст

Нужна модель для превращения текстовых чанков в векторы (embeddings). Есть два стандартных пути: облачный API (OpenAI/etc.) или локальная модель через `sentence-transformers`.

## Решение

Используем `sentence-transformers`, модель `all-MiniLM-L6-v2`, локально.

## Обоснование

- Бесплатно и без API-ключа — важно на учебном этапе, где нужно свободно экспериментировать без счётчика токенов.
- Работает офлайн.
- Компромисс: ниже качество семантического поиска, чем у топовых моделей OpenAI.

## Последствия

Интерфейс `search()` не завязан на конкретного провайдера embeddings — замена на OpenAI в будущем потребует изменить только реализацию получения векторов, не сам пайплайн поиска.
