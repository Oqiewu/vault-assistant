# 0002 — Chunking: скользящее окно с перекрытием

**Статус:** принято, не пересмотрено экспериментально — 2026-09-13

## Контекст

Заметки нужно резать на куски перед embedding — модель имеет лимит длины, и слишком крупный чанк размывает смысл при поиске.

## Решение

Скользящее окно: `chunk_size=700`, `overlap=100` символов (`chunk_text` в `chunk_vault.py`).

## Обоснование

Разумные значения по умолчанию для старта — не результат тюнинга. Overlap нужен, чтобы не резать мысль ровно на границе чанка.

## Последствия

Если качество поиска (Слой 1) окажется плохим на реальных запросах — пересмотр `chunk_size`/`overlap` первый кандидат на эксперимент.
