# 0004 — Невалидный YAML во frontmatter не должен ронять пайплайн

**Статус:** принято — 2026-09-13

## Контекст

Часть заметок в vault содержит Templater-плейсхолдеры (`<% tp.date.now(...) %>`) в frontmatter — это не валидный YAML, `yaml.safe_load` падает с `ParserError`.

## Решение

`parse_note` в `chunk_vault.py` оборачивает `yaml.safe_load(frontmatter_raw)` в `try/except yaml.YAMLError`, при ошибке возвращает `metadata = {}`.

## Обоснование

Тело заметки для RAG важнее метаданных — файл не должен выпадать из индекса целиком из-за сломанного frontmatter, который парсится отдельно от тела.

## Последствия

Файлы с невалидным frontmatter теряют метаданные (tags, Дата) при индексации, но их текст всё равно участвует в поиске.
