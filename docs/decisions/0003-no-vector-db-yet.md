# 0003 — Без векторной БД на текущем этапе

**Статус:** принято, временное — 2026-09-13

## Контекст

Embeddings нужно где-то хранить между запросами. Варианты: персистентная векторная БД (Chroma, pgvector) или пересчёт в памяти при каждом запуске.

## Решение

Пока без БД — embeddings считаются в памяти при каждом запуске скрипта.

## Обоснование

На объёме 4864 чанка из 533 файлов пересчёт занимает ~2 минуты — приемлемо для итеративной разработки на учебном этапе.

## Последствия

Пересмотреть при переходе к Слою 4 (FastAPI, постоянно работающий сервис) — пересчитывать embeddings на каждый HTTP-запрос неприемлемо. Кандидаты: Chroma (просто, локально) или pgvector (раз уже есть PostgreSQL в стеке).
