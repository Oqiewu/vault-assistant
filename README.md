# VaultAssistant

RAG-система поверх личного Obsidian vault — отвечает на вопросы по заметкам со ссылками на источники.

## Стек

Python, sentence-transformers (embeddings), LangGraph/FastAPI.

## Запуск

```powershell
venv\Scripts\Activate.ps1
python embed.py
```
